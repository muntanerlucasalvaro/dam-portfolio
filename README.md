Prácticas, ejercicios y exámenes del **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**, cursado en el CIDE (Palma de Mallorca).

## Contenido

| Módulo | Qué incluye | Tecnologías |
|---|---|---|
| [Programación](dam-portfolio/PROGRAMACION) | Unidades 1 a 8: fundamentos, POO, colecciones, interfaces gráficas con Swing y LayoutManager, ficheros y acceso a datos | Java |
| [Bases de Datos](dam-portfolio/BASES%20DE%20DATOS) | Diseño relacional y consultas SQL (unidades 0 a 3) | SQL |
| [Entornos de Desarrollo](dam-portfolio/ENTORNOS%20DE%20DESARROLLO) | Diagramas de secuencia, recursividad y actividades de las unidades 1 a 3 | Java · UML |
| [Lenguaje de Marcas](dam-portfolio/LENGUAJE%20DE%20MARCAS) | Maquetación web con HTML y CSS, y examen práctico | HTML · CSS |

## Cómo ejecutar los proyectos Java

Cada actividad es un proyecto independiente. Ábrelo con IntelliJ IDEA, NetBeans o VS Code y ejecuta la clase que contiene el método `main`.
